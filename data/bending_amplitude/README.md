# Bending amplitude

Block analysis of the linear force-balance response u = H⁺f for eight compressed structures: Mg(Sc<sub>1−x</sub>Sb<sub>x</sub>)<sub>2</sub>Se<sub>4</sub> x = 0.75 (k12, 4→5 GPa and 0→5 GPa) and x = 0.5 (k08), Cd(Ga,In)<sub>2</sub>O<sub>4</sub>, layered Na(Sc,In)O<sub>2</sub>, CaTiO<sub>3</sub>, CaSnO<sub>3</sub>, Ca<sub>2</sub>SnTiO<sub>6</sub> and Ca<sub>8</sub>Sn<sub>6</sub>Ti<sub>2</sub>O<sub>24</sub> (0→5 GPa unless stated). Existing force constants only; no new DFT.

- Coordinates are split into p (bond-preserving network motion, kernel of the B–X bond Jacobian), q (bond-changing network motion, the bond-tension directions) and A (A-cation motion). The block equation u<sub>p</sub> = K<sub>pp</sub><sup>−1</sup>(f<sub>p</sub> − K<sub>pq</sub>u<sub>q</sub> − K<sub>pA</sub>u<sub>A</sub>) separates direct drive from coupling-generated bending; k<sub>pp</sub>, k<sub>qq</sub> are mean Rayleigh quotients of the diagonal blocks.
- `amplitude.json` (from `amplitude.py`): drive, predicted and actual bond-preserving shares, bending channels, block model, stiffnesses, K<sub>pp</sub> mode weights and local descriptors (B–X size mismatch, octahedral bond spread, bridge-angle spread) per structure.
- `symmetric_sector_blocks.json` (from `symmetric_sector_blocks.py`): the same block model with the blocks taken inside the symmetric sector (p<sub>s</sub> = sector motions with J x<sub>net</sub> = 0 and x<sub>A</sub> = 0). It reproduces `amplitude.json` where the bond projector commutes with the sector projector, and it is the valid split for k12 0→5 GPa (space group Cm), where the projection used in `amplitude.py` leaks (leak 4.9) and the block entries of that structure in `amplitude.json` are not meaningful.
- `sector_force_balance/*/p0_p5/`: case definition (`meta.json`), sector basis `S.npy` and per-displacement forces `hessian/*/forces.npy` from which H<sub>s</sub> is built, and, for k12, geometry, force-balance and four-state read-outs of the 0→5 GPa run (symmetric-sector Hessian; for k12 90 degrees of freedom, 182 finite-difference displacements). The other five structures are read from `../bending_enrichment/full_force_balance` and `../bending_enrichment/sector_force_balance`.
- k12 0→5 GPa: drive share 0.42%, predicted 32.0%, actual 32.6%; cos(H⁻¹f, u) = 0.9991; harmonic and DFT energy lowering −155.6 and −156.0 meV; the conduction margin Λ<sub>C</sub> changes from −22.4 to +6.8 meV (bond-preserving part +24.7 meV, φ = 0.82).
