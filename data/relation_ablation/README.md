# Relation ablation

Ablation and sensitivity analyses of the colocation relations of the spinel structural database (single-coordinate Π<sub>sp</sub> on its 442 search structures with the protocol labels; double-coordinate Π<sub>V</sub>, Π<sub>C</sub> on the 440 development structures with the canonical edge labels; data of `spinel_relations/colocation_relation`, coefficients unchanged), and frozen-phonon tests on Mg(Sc<sub>1−x</sub>Sb<sub>x</sub>)<sub>2</sub>Se<sub>4</sub> x = 0.75 (k12, 5 GPa), CaTiO<sub>3</sub> and CaSnO<sub>3</sub>.

- Feature roles: local = single element or single octahedron (elem_\*, alloy_\*, BX_\*_mismatch, BX_distance_skew, BX6_\*, D_BX6_\*, D_XBX_\*, G_XBX_\*, BX_t_pd_\*, onsite_alignment_inverse, B_d_filling_mean); network = two B or B–X–B / X–X connections (BXB_\*, D_BXB_\*, BB_\*, XX_\*); global = lattice_angle_anisotropy. Neutralisation replaces a feature by its median over the evaluation set and refits only the decision threshold (orientation fixed); 200 random permutations are a sensitivity check.
- `neutralisation_ablation.csv` (`neutralisation_ablation.py`): group neutralisation with Π<sub>sp</sub> scored against the canonical colocation labels. `t1_t2_results.json` (`t1_t2_ablation.py`): single-feature and group neutralisation (T1) and the terms of Π<sub>V</sub>, Π<sub>C</sub> near the boundary and along S01–S14 (T2); `t2c_path_terms.csv` holds the path terms. Summary in `t1_t2_results.md`.
- `descriptor_sensitivity/`: sensitivity |dΠ/dε| along 20 random bond-preserving and 20 bond-changing network directions (seeds 0–19 and 100–119, ±0.01 Å maximum atomic displacement, centroid removed, A site fixed) of the canonical S05, S06, S11, S12 structures; features recomputed from the structures with `symbolic_regression/inputs/spinel_descriptors.py` (structure and element tables in `descriptor_tables/structures/`; `displace_structures.py` → `features.csv`, `sensitivity_eval.py` → `sensitivity_results.json`, `sensitivity_derivatives.csv`; retained descriptor names in `retained_names.json`); `compare_recomputed_features.py` → `recomputed_feature_comparison.json` compares recomputed and stored features (maximum relative error 1.7e−13).
- `phonon_mode_response/`: eigenmodes of the mass-weighted dynamical matrix of the full H (k12 4→5 GPa, perovskites 0→5 GPa; translations removed), classified by the bond-preserving share of their network part (≥ 0.7 bending, ≤ 0.3 stretching), the six lowest of each class displaced by ± (0.04 Å maximum atomic displacement) about the 5-GPa structure (`prepare_modes.py` → `modes.json`; k12 reference structure `ref_k12/POSCAR`; OSZICAR of every displaced static in `<system>/<mode>_<sign>/`). Statics: k12 4×4×4 Γ-centred, ISYM = 0, ISMEAR = −5, NBANDS = 172; perovskites 8×6×8, ISYM = 0, ISMEAR = 0. `mode_response_readout.py` → `mode_response_results.json`, `mode_table.csv`: deformation potential per unit energy |∂²Λ/∂Q²|/ω², and at 300 K the renormalisation ΔΛ<sub>T</sub> = ½Σ∂²Λ/∂Q²⟨Q²⟩ and fluctuation σ² = Σ(∂Λ/∂Q)²⟨Q²⟩ with ⟨Q²⟩ = (ħ/2ω)coth(ħω/2k<sub>B</sub>T), summed over the sampled Γ modes only (the soft k12 bending modes reach 2.0–2.7 times the sampled amplitude at 300 K).
- `order_dependence/`: Λ<sub>C</sub> of the state X (5-GPa fractional coordinates in the 4-GPa lattice, `poscar_x`; static in `state_x/`) to test the order dependence of the 4→5 GPa split; `order_readout.py` → `order_result.json`, competing point fixed at R of the 5-GPa structure. `closed_loop_diagnosis.md` collects how the switches decompose along the substitution and pressure paths.
