# Substitution and pressure path split

Basis-free split of the band-edge margin changes Λ<sub>V</sub> = E<sub>V</sub>(Γ) − max<sub>k≠Γ</sub>E<sub>V</sub>(k) and Λ<sub>C</sub> = min<sub>k≠Γ</sub>E<sub>C</sub>(k) − E<sub>C</sub>(Γ) (4×4×4 Γ-centred mesh) into sequential operations, from DFT statics only, along two paths of Mg(Sc<sub>1−x</sub>Sb<sub>x</sub>)<sub>2</sub>Se<sub>4</sub> (56-atom cells).

- Composition path S01→S14 (nested CHGNet-relaxed cells, one more Sc→Sb per step): ΔΛ = Δchem + Δlat + Δint with the states chem (new species on the old geometry), aff (new species, old fractional coordinates in the new lattice) and the new structure; network response Δnet = Δlat + Δint.
- Pressure path 0→2→3→4→5→6 GPa (tight DFT relaxations; the 7.5 GPa relaxation did not converge and is excluded): ΔΛ = Δlat + Δint with aff = old fractional coordinates in the new lattice.
- Statics: PBE, ENCUT 520 eV, PREC Accurate, EDIFF 1e−5, ISMEAR 0, SIGMA 0.05, LREAL Auto, PAW Mg/Sb/Sc_sv/Se, ISYM = 0. Within a step the competing k point is fixed at the end state; the values with each state's own competing point are also given.
- `path_split.json` (from `path_readout.py`): per-step components for both paths, endpoint margins, and sign summaries in `evaluation` (F1: steps with Δchem and Δnet of opposite sign; F2: |Δchem| vs |Δnet| at the switching steps S05→S06 (Λ<sub>V</sub>) and S11→S12 (Λ<sub>C</sub>); F3: steps with Δint and Δlat of opposite sign on the pressure path; F4: |Δlat| vs |Δint| for Λ<sub>C</sub> at 4→5 GPa). A sign is counted only when both parts are at least 5 meV.
- `path_prepare.py` writes the static inputs and the atom correspondence (MAPPING.json) from `inputs/` (CHGNet-relaxed `s01_contcar.vasp`…`s14_contcar.vasp`, tight-relaxed `p0_contcar.vasp`…`p7_5_contcar.vasp`, `static_k4_p4_incar`; the POTCAR is read from the cluster and not deposited); `path_readout_local.py` is the same read-out with the pressure-path reference statics taken from a local copy.
